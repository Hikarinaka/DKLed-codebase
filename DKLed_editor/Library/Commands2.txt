Command:
Command name = "Set amount of frames to play until stopped"
Command Description = "Sets video sequence from memory (Fast Video sequence) in a state that it will be played until stopped from a button or another command. When amount of frames to play setting is in this mode, controller will continue reading and executing scenario file during playing video sequence to be able to perform other duties including stop playing the sequence in time"
Command Stackable = Yes
Command Start text= "G35P0"

Command:
Command name = "Stop playing Fast Video sequence"
Command Description = "Interrupts playing video sequence from memory (Fast Video sequence). If there was finite amount of frames to play, this also triggers controller to continue reading and executing current scenario file"
Command Stackable = Yes
Command Start text= "G36P0"

Command:
Command name = "Start playing Fast Video sequence"
Command Description = "Begins playing video sequence from memory (Fast Video sequence) according to previousely set frequency, amount of frames to play and other Fast Video parameters as soon as the next Output command (G4 or G6 commands) will be called. If this command called from a button, starts playing immedialtelly"
Command Stackable = Yes
Command Start text= "G36P1"
